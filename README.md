# stackd

stackd is a three-sided marketplace for guests, hosts, and vendors, with an AI trip planner.

## Setup

You need Node.js and npm. Copy `.env.example` to `.env` and fill in your own values. Do not commit `.env`.

```sh
npm i
npm run dev
```

## Tech

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS
- Supabase
